# API C : file d'événements `vc_poll` (squelette)

Ajout dans `bindings/c/` de la structure `vc_event` (`const char* actor`, `const char* action`)
et de `int vc_poll(vc_controller* controller, vc_event* out)` : retire l'événement le plus
ancien de la file ; retourne 1 si `out` est rempli, 0 si la file est vide, -1 en cas
d'erreur (paramètre NULL). Les chaînes restent valides jusqu'au prochain `vc_poll` ou
`vc_destroy`. Ajout compatible : `vc_api_version()` reste à 1.

**État : la file n'est pas encore alimentée** : `vc_handle_text` exécute les ordres sans y
ajouter d'événement, donc `vc_poll` retourne toujours 0 pour l'instant.

`test_c_api` réécrit avec une fonction `check(condition, description)` qui affiche OK / FAILED
par vérification ; teste NULL rejeté et file vide au départ.
